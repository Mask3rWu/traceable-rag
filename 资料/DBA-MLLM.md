# 坦克目标毁伤评估标准（适用于MLLM）

## 一、评估概述

本标准基于《目标毁伤评估标准》，针对坦克目标建立适合多模态大语言模型（MLLM）进行毁伤评估的等级划分和判定方法。

**输入要求**：
- 图片：坦克打击后图像
- 提示词：预先设定的毁伤评估提示词

**输出要求**：
- 毁伤等级（Ⅰ级/Ⅱ级/Ⅲ级）
- 功能状态评估
- 视觉特征描述

---

## 二、坦克关键部件视觉特征

| 序号 | 关键部件 | 功能说明 | 毁伤视觉特征 |
|-----|---------|---------|-------------|
| 1 | 炮塔 | 安装武器系统和观瞄设备 | 形状变化、移位、卡死、倾斜、被掀翻 |
| 2 | 主炮 | 主要攻击武器 | 弯曲、断裂、变形、炮口损毁 |
| 3 | 发动机/传动系统 | 提供动力 | 冒烟、起火、不运转 |
| 4 | 履带行走系统 | 支撑和移动 | 断裂、脱落、断续、履带板散落 |
| 5 | 观瞄系统 | 目标搜索和瞄准 | 破损、镜头碎裂、遮挡 |
| 6 | 装甲防护 | 抵御攻击 | 穿孔、凹坑、裂纹、脱落 |
| 7 | 弹药储存区 | 存放弹药 | 起火、殉爆痕迹、弹药外露 |
| 8 | 车身整体 | 主体结构 | 变形、断裂、解体、焚毁 |

---

## 三、毁伤等级划分（3级）

### Ⅰ级（轻度毁伤）

| 判定条件 | 功能影响 | 典型视觉特征 |
|---------|---------|-------------|
| 非关键部件轻微损伤，装甲表面凹痕 | 战斗能力基本正常，可继续执行任务 | - 装甲表面轻微凹痕（凹坑深度 < 10mm）<br>- 涂层剥落、伪装网损坏<br>- 观察窗轻微裂纹<br>- 外挂设备（如天线、油桶）轻微损坏<br>- 履带轻微损坏 |
| **可修复性** | 战场可快速修复，< 2小时 |  |

### Ⅱ级（中度毁伤）

| 判定条件 | 功能影响 | 典型视觉特征 |
|---------|---------|-------------|
| 关键部件损坏，机体结构局部破损 | 主要功能部分受限，需要维修才能继续作战 | - 装甲被击穿（单一穿透孔洞）<br>- 履带断裂或脱落<br>- 发动机部分损坏（冒烟但未起火）<br>- 观瞄设备损坏（镜头破碎）<br>- 炮塔旋转部分受阻 |
| **可修复性** | 需要后送维修，2~24小时 |  |

### Ⅲ级（重度毁伤/毁灭）

| 判定条件 | 功能影响 | 典型视觉特征 |
|---------|---------|-------------|
| 主体结构严重破损，多个关键部件损坏或完全损坏 | 主要功能丧失，无法继续作战 | - 装甲大面积破损（多个穿孔或严重变形）<br>- 炮塔被掀翻、卡死或移位<br>- 主炮严重变形或断裂<br>- 发动机完全失效（起火或完全焚毁）<br>- 弹药殉爆（车体大面积烧毁、弹药外露）<br>- 车体断裂或解体<br>- 整体焚毁（只剩残骸骨架） |
| **可修复性** | 需要工厂级大修，> 24小时，或判定报废，无修复价值 |  |

## 四、评估决策树

```
输入：坦克图片 + 提示词
          ↓
    ┌─────────────────────────────────────────┐
    │ 观察1：车体是否完整？                    │
    └─────────────────────────────────────────┘
          ↓
    ├─ 完整 → 观察装甲表面是否有明显穿孔或凹坑
    │           ↓
    │       ├─ 仅表面凹痕 → Ⅰ级（轻度毁伤）
    │       ├─ 有单一穿孔 → Ⅱ级（中度毁伤）
    │       └─ 有大面积破损 → 进入关键部件评估
    │
    └─ 不完整（断裂/解体） → 直接判定 Ⅲ级（重度毁伤）
    
    ┌─────────────────────────────────────────┐
    │ 观察2：是否有起火、焚毁痕迹？            │
    └─────────────────────────────────────────┘
          ↓
      ├─ 有（弹药殉爆、发动机起火） → Ⅲ级（重度毁伤）
      └─ 无 → 继续评估
      
    ┌─────────────────────────────────────────┐
    │ 观察3：关键部件（炮塔、主炮、履带）状态 │
    └─────────────────────────────────────────┘
          ↓
      ├─ 炮塔被掀翻/卡死 或 主炮断裂 → Ⅲ级（重度毁伤）
      ├─ 履带断裂/脱落 → Ⅱ级（中度毁伤）
      ├─ 履带完好 + 装甲完好 → Ⅰ级（轻度毁伤）
      └─ 其他部件损坏 → 根据损坏程度综合判定
```

## 五、MLLM提示词模板

```
## 坦克毁伤评估任务

### 任务说明
你是一名毁伤评估专家，需要根据提供的坦克图片，判断其毁伤等级。

### 毁伤等级定义
- **Ⅰ级（轻度毁伤）**：装甲表面轻微凹痕、涂层剥落、观察窗轻微裂纹、外挂设备轻微损坏。战斗能力基本正常，可继续执行任务。修复时间 < 2小时。

- **Ⅱ级（中度毁伤）**：装甲被击穿（单一穿孔）、履带断裂或脱落、发动机部分损坏、观瞄设备损坏、炮塔旋转部分受阻。主要功能部分受限，需要维修才能继续作战。修复时间 2~24小时。

- **Ⅲ级（重度毁伤/毁灭）**：装甲大面积破损、炮塔被掀翻或卡死、主炮严重变形或断裂、发动机完全失效（起火/焚毁）、弹药殉爆（车体大面积烧毁）、车体断裂或解体、整体焚毁。主要功能丧失，无修复价值。

### 评估要点
1. 观察车体完整性：是否完整、断裂或解体
2. 检查装甲状态：是否有穿孔、凹坑、破损
3. 评估关键部件：炮塔位置、主炮状态、履带是否完好
4. 判断毁伤特征：起火痕迹、焚毁痕迹、弹药外露

### 输出格式
请按以下格式输出：
1. 主体完整性：[完整/断裂/解体]
2. 毁伤特征：[起火/焚毁痕迹]；[装甲破损情况]；[关键部件状态]
3. 功能状态：仅输出能从视觉判断为受损的功能，未观察到的功能不输出（如：[运动功能受损]；[攻击功能受损]）
4. 毁伤等级：[1级/2级/3级]
```

## 六、视觉特征与毁伤等级对照表

| 视觉特征 | 对应毁伤等级 |
|---------|-------------|
| 装甲表面轻微凹痕（< 10mm） | Ⅰ级 |
| 涂层剥落、伪装网损坏 | Ⅰ级 |
| 观察窗轻微裂纹 | Ⅰ级 |
| 外挂设备（天线、油桶）轻微损坏 | Ⅰ级 |
| 装甲被击穿（单一穿孔） | Ⅱ级 |
| 履带断裂或脱落 | Ⅱ级 |
| 发动机部分损坏（冒烟） | Ⅱ级 |
| 观瞄设备损坏（镜头破碎） | Ⅱ级 |
| 炮塔旋转受阻 | Ⅱ级 |
| 装甲大面积破损 | Ⅲ级 |
| 炮塔被掀翻/卡死 | Ⅲ级 |
| 主炮严重变形或断裂 | Ⅲ级 |
| 发动机起火 | Ⅲ级 |
| 弹药殉爆痕迹 | Ⅲ级 |
| 车体断裂或解体 | Ⅲ级 |
| 整体焚毁 | Ⅲ级 |

## 七、快速判定规则

### 直接判定为Ⅰ级的情形
- 装甲表面仅有凹痕，无穿孔
- 履带完好
- 无起火、焚毁痕迹

### 直接判定为Ⅲ级的情形
- 车体断裂、解体
- 整体焚毁
- 炮塔被掀翻或与车体分离
- 主炮断裂或炮口损毁严重
- 弹药殉爆（弹药外露、大面积烧毁）

### 其他情况综合判定为Ⅱ级
- 有穿孔但非大面积破损
- 部分部件损坏但非完全失效

## 八、评估示例

### 示例1
**图像描述**：坦克装甲表面有多个明显凹坑，未见穿孔，履带完好，无起火痕迹，炮塔位置正常。

**评估结果**：
1. 主体完整性：完整
2. 毁伤特征：无起火/焚毁痕迹；装甲表面凹坑但无穿孔；履带完好、炮塔位置正常
3. 功能状态：无（从视觉无法判断任何功能受损）
4. 毁伤等级：1级

### 示例2
**图像描述**：坦克装甲侧面有一个穿孔，履带断裂脱落，发动机舱有烟冒出，炮塔可正常旋转。

**评估结果**：
1. 主体完整性：完整
2. 毁伤特征：无起火/焚毁痕迹；装甲侧面有一个穿孔；履带断裂脱落、发动机部分损坏（冒烟）、炮塔可正常旋转
3. 功能状态：运动功能受损
4. 毁伤等级：2级

### 示例3
**图像描述**：坦克车体断裂成两截，炮塔与车体分离，散落在地，主炮严重变形，整车大面积烧毁痕迹。

**评估结果**：
1. 主体完整性：解体
2. 毁伤特征：大面积焚毁痕迹；装甲大面积破损；炮塔与车体分离、主炮严重变形
3. 功能状态：运动功能受损；攻击功能受损；侦查功能受损
4. 毁伤等级：3级
